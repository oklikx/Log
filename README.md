# Log Analyzer

Скрипт на Python 3 для анализа файлов `access.log`.

## Возможности

- Анализ одного файла или всех файлов в директории.
- Сбор статистики за один проход по файлу (корректно работает с большими логами).
- Для каждого файла формируется отдельный JSON и отдельный вывод в терминал.
- Топ-N самых долгих запросов поддерживается через `heapq` — O(log N) на строку.
- Корректно разбирает строки с экранированными кавычками `\"` в полях
  `%r`, `%{Referer}`, `%{User-Agent}`.

## Собираемая статистика

- Общее количество запросов.
- Количество запросов по HTTP-методам: GET, POST, PUT, DELETE, OPTIONS, HEAD.
  Все 6 методов всегда присутствуют в JSON, даже если их 0.
- Топ-3 IP-адресов по числу запросов.
- Топ-3 самых долгих запросов: метод, URL, IP, длительность, дата и время.
